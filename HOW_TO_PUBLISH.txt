Factory Game v5 - web version
=============================

These files ARE the web page (index.html + the game engine in index.wasm + the game data in index.pck).
They must be served by a web server: double-clicking index.html does not work (browsers block it).

Publish it (free):
  * itch.io : create a project, Kind of project = HTML, upload a ZIP of these files,
              tick "This file will be played in the browser", viewport 1280 x 720 (or "fullscreen button").
  * GitHub Pages / Netlify / any web host : put all these files in a folder of the site; the game is index.html.
  This build is single-threaded: no special server settings are needed.

Try it on your PC:
  * In the Godot editor (v5 project): the "Remote Debug / Run in browser" button (top right, HTML5 icon), or
  * With Python installed: open a terminal in this folder and run   python -m http.server 8000
    then open http://localhost:8000 in Chrome / Edge / Firefox.

Notes:
  * Saves and saved layouts are stored in the browser (per site, per browser).
  * "Export CSV" works but the file stays inside the browser storage on the web version.
  * Re-export after changes: Godot > Project > Export > "Web" > Export Project (the preset is already in v5).
